# Formagen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy Formagen v1, a server-driven form builder (builder, versioned publishing, public form page, responses dashboard) on Next.js + GraphQL + AWS, with Playwright, axe and Lighthouse checks in CI.

**Architecture:** One Next.js App Router app. A shared Zod form-schema (`lib/schema`) drives the renderer, the builder preview and server-side validation. Admin screens call a GraphQL API (Yoga + Pothos) over a service layer (`lib/forms`); the public page calls the service layer directly from a Server Component and a Server Action. Postgres via Drizzle (Neon in prod, PGlite in tests). Deployed to AWS with SST.

**Tech Stack:** Next.js (App Router, latest stable), TypeScript strict, Zod, Drizzle ORM, Neon Postgres, PGlite (tests), Auth.js v5, GraphQL Yoga, Pothos, GraphQL Codegen, TanStack Query, Zustand, dnd-kit, Radix (Dialog/Popover only), CSS Modules, Vitest, React Testing Library, Playwright, @axe-core/playwright, Lighthouse CI, SST v3, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-09-formagen-design.md` (copied into the repo in Task 1).

## Global Constraints

- Repo: `~/code/formagen`, remote `github.com/Allencrspy/formagen`; commits authored by Allen Binu Thomas.
- Package manager: pnpm. Node: current LTS. Install every dependency at its latest stable version; no beta/canary.
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`. No `any` outside generated code.
- Field types exactly: `shortText`, `longText`, `email`, `number`, `select`, `checkbox`, `date`.
- Form schema JSON carries `schemaVersion: 1`.
- Public form page route `/f/[slug]`; must submit with JavaScript disabled.
- Responses table page size: 25, newest first.
- Accessibility target: WCAG 2.2 AA, 0 axe violations on builder, public page and dashboard.
- AWS budget alert at $5/month. Neon free tier for Postgres.
- Every measured number goes in `docs/metrics.md` with date and commit hash. No unmeasured numbers anywhere.
- The test-login (Credentials) provider exists only when `E2E_TEST_LOGIN=1`; never set in prod.

## Review Focus

1. **Hidden conditional field submitted with a value (no-JS page posts every field):** the answer is dropped and its validation skipped. Test in Task 3.
2. **Draft edited after publish so a `showIf` points at a deleted or later field:** saving is rejected with an issue on that field, never a broken public form. Test in Task 2.
3. **Responses from an older version after a new publish:** still listed, filterable by version, shown with that version's columns. Test in Task 7.
4. **CSV export of a value starting with `=`, `+`, `-` or `@`:** cell is prefixed with `'` so spreadsheets don't run it as a formula. Test in Task 14.
5. **Prod build with the test-login provider:** the providers list contains only GitHub unless `E2E_TEST_LOGIN=1`. Test in Task 5.
